# Öğrenci Yurt Yemek Sistemi

Öğrenci yurtlarındaki öğrenci kayıtlarını, oda atamalarını ve yemek geçişlerini yönetmek için geliştirilmiş bir Windows Forms uygulamasıdır.

## 📋 Özellikler

### Öğrenci Yönetimi
- ✅ Öğrenci ekleme, düzenleme ve silme
- ✅ Öğrenci bilgileri (Ad, Soyadı, Numara, TC Kimlik No)
- ✅ Öğrenci listesi görüntüleme
- ✅ Veriye bağlı DataGridView görünümü

### Yurt Yönetimi
- ✅ Öğrenciye oda atama
- ✅ Yurt kaydı ekleme, güncelleme ve silme
- ✅ Oda numarası yönetimi (101-110)
- ✅ Öğrenci durumu takibi (Kalıyor/Boş)
- ✅ Aktiflik durumu yönetimi


### Filtreleme
- ✅ Tüm kayıtları görüntüleme
- ✅ Aktif kayıtları filtreleme
- ✅ Pasif kayıtları filtreleme

## 🛠️ Teknolojiler

- *Framework:* .NET Framework 4.7.2
- *Dil:* C# 7.3
- *Veritabanı:* SQL Server (Entity Framework 6.x)
- *UI:* Windows Forms
- *ORM:* Entity Framework

## 📦 Sistem Gereksinimleri

- Windows 7 veya üzeri
- .NET Framework 4.7.2
- SQL Server 2012 veya üzeri
